## 🔭 研究方向

<p align="center">
  <b>学生研究者 · 上海财经大学（SUFE）</b>
</p>

- 🛡️ **AI Agent 安全** — 提示注入、工具调用风险、记忆投毒与生命周期防御
- 🧪 **评测与红队** — 可复现基准、攻防指标与多模型裁判
- 🖥️ **GUI Agent 安全** — 桌面、移动、Web 与跨设备工作流安全评测
- 📊 **统计智能** — 面向真实数据分析的可靠、可执行 Agent 工作流

## 🧭 项目亮点

- 构建覆盖 **3 类平台** 与跨设备威胁路径的统一 GUI Agent 安全框架。
- 基于 **4,000 条真实、可溯源监管处罚案例** 构建金融红队流水线，源案例不使用大模型合成。
- 发布带自动完整性校验与隐私泄漏检查的匿名金融 Agent 安全数据集。
- 为数据分析 Agent 增加统计工具、会话隔离与本地降级能力。
